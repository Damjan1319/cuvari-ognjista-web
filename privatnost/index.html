Čuvari Ognjišta – Politika privatnosti

Poslednja izmena: 16. novembar 2026.

Igru Čuvari Ognjišta objavljuje DS Code (dscode.rs). Ova stranica objašnjava koje podatke igra koristi.

Koje podatke prikupljamo

Nikakve. Igra ne traži nalog, ne prikuplja lične podatke, nema reklame, ne koristi analitiku i ne šalje podatke na internet.

Šta se čuva na uređaju

Napredak u igri (nivoi, junaci, zgrade, podešavanja zvuka) čuva se samo na tvom uređaju. Ti podaci nikada ne napuštaju uređaj i brišu se kada obrišeš igru ili njene podatke.

Deca

Igra ne prikuplja podatke ni od koga, pa ni od dece.

Izmene

Ako buduće verzije igre uvedu mrežne mogućnosti (na primer table rezultata sa drugim igračima), ova stranica će biti dopunjena pre izlaska te verzije.

Čuvari Ognjišta – Privacy Policy

Last updated: November 16, 2026.

Čuvari Ognjišta is published by DS Code (dscode.rs). This page explains what data the game uses.

Data we collect

None. The game requires no account, collects no personal data, shows no ads, uses no analytics and sends no data over the internet.

Data stored on your device

Game progress (levels, heroes, buildings, sound settings) is stored only on your device. It never leaves the device and is removed when you uninstall the game or clear its data.

Children

The game does not collect data from anyone, including children.

Changes

If future versions add online features (for example leaderboards with other players), this page will be updated before that version is released.
